Phishing Link Check demo

Serve this page with python -m http.server -d extension 8000 and open http://localhost:8000/demo.html with the extension loaded unpacked (content scripts don't run on file://). Hover over the links, then click them. The phishing hosts come from eval/real_world_urls.csv. They are made up, but someone could register one, so don't choose "Open anyway" unless you mean to.
